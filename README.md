# Fibonacci Generator Web App using Django

This is a simple web application built using **Django** in PYcharm to generate the Fibonacci sequence up to a number entered by the user.

## Introduction to Django

[Django](https://www.djangoproject.com/)  is a high-level Python web framework that allows rapid development of secure and maintainable web applications. It provides a clean and pragmatic design for developing web applications, with features like automatic admin interfaces, object-relational mapping (ORM), routing, and much more.

In this project, I used Django to create a basic web app where users can input a number and receive the Fibonacci sequence for that number. The app is styled with CSS to be user-friendly and visually appealing.

## Features

* Fibonacci sequence generator.
* Responsive design with centered content.
* Clean and minimalistic UI.

## Technologies Used

* **Python 3.x**
* **Django 5.2** (latest version)
* **HTML & CSS** for frontend
* **Browser** for testing (localhost)

## Key Steps and Code Explanation

### 1. **Setup Django Project**

First, we set up a Django project by creating a new directory for it and running the command:

```bash
django-admin startproject fiboproject
cd fiboproject
```

### 2. **Create Fibonacci App**

We then create a new app within the Django project where we will implement the Fibonacci logic:

```bash
python manage.py startapp fibonacci
```

### 3. **Define URLs**

In `fiboproject/urls.py`, we include the URL pattern for the Fibonacci app:

```python
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('', include('fibonacci.urls')),  # Link to the Fibonacci app
]
```

Inside the `fibonacci/urls.py`, we define a route for the Fibonacci view:

```python
from django.urls import path
from .views import fibonacci_view

urlpatterns = [
    path('', fibonacci_view, name='fibonacci'),
]
```

### 4. **Create View Logic**

In `fibonacci/views.py`, the core logic for generating the Fibonacci sequence is written. We retrieve the user input, compute the sequence, and render it back to the user.

```python
from django.shortcuts import render

def fibonacci_view(request):
    sequence = []
    n = request.GET.get('n')
    if n and n.isdigit():
        n = int(n)
        a, b = 0, 1
        for _ in range(n):
            sequence.append(a)
            a, b = b, a + b
    return render(request, 'fibonacci/fibonacci.html', {'sequence': sequence})
```

Here, `request.GET.get('n')` captures the user input (`n`), and the Fibonacci sequence is generated by iterating through a loop and updating the variables `a` and `b` to produce the sequence.

### 5. **Create HTML Template**

In the `fibonacci/templates/fibonacci/fibonacci.html` file, we create the form for user input and display the Fibonacci sequence. We use Django's templating language to render the sequence dynamically.

```html
<form method="get">
    <label for="n">Enter number of terms:</label>
    <input type="number" id="n" name="n" required min="1">
    <button type="submit">Generate</button>
</form>

{% if sequence %}
    <div class="output">
        <h3>Fibonacci Sequence:</h3>
        <p>{{ sequence|join:", " }}</p>
    </div>
{% endif %}
```

This form takes a number `n` from the user and displays the resulting Fibonacci sequence once it's generated.

### 6. **Styling the App**

CSS is used to style the form and display the Fibonacci sequence. The page content is centered using Flexbox, and we applied basic styles for an attractive, responsive layout.

```css
.container {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 100vh;
    text-align: center;
}
```

### 7. **Run the Server**

Finally, you can run the Django development server to test your app:

```bash
python manage.py runserver
```

Navigate to `http://127.0.0.1:8000/` in your browser, and you will be able to input a number and see the corresponding Fibonacci sequence.
